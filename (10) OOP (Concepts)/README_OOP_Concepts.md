# OOP as it Should Be — Concepts

> *Understand Object-Oriented Programming the right way, at the right time.*

---

## About This Folder

This folder contains my practice projects and exercises from the *OOP as it Should Be – Concepts* course, part of the Programming Advices Roadmap.

This course is placed exactly where OOP should be learned — after building a strong procedural programming foundation. By this point, the question is no longer *how to write code*, but **how to design it**.

OOP is introduced here as a design mindset, not as syntax. As a solution to real problems, not as theory.

---

## What This Course Teaches

- What OOP is and why it exists as a natural evolution after procedural programming
- The difference between procedural thinking and OOP thinking
- How to design and use classes and objects correctly
- How objects live in memory
- Access specifiers, properties, and encapsulation
- Constructors, destructors, and copy constructors
- Static members and methods
- Inheritance — how and when to use it safely
- Polymorphism, virtual functions, and dynamic binding
- Interfaces, abstract classes, and pure virtual functions
- How to organize code into reusable libraries and components
